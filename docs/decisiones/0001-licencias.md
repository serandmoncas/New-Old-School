# 0001 · Licencias del proyecto

- **Estado**: aceptada
- **Fecha**: 2026-10-12
- **Decide**: Coordinación

## Contexto

El proyecto mezcla software (la plataforma) y contenido educativo. Queremos máxima reutilización y que las mejoras al contenido vuelvan a la comunidad.

## Opciones consideradas

1. **Todo MIT** — simple, pero MIT no está pensada para texto educativo y no obliga a compartir mejoras.
2. **Código MIT + contenido CC BY-SA 4.0** — estándar de Wikipedia y OpenStax-like; las adaptaciones del contenido siguen abiertas.
3. **Código AGPL + contenido CC BY-SA** — protege más el código, pero desalienta a instituciones que quieran integrarlo.

## Decisión

Código bajo **MIT**; contenido bajo **CC BY-SA 4.0**.

## Consecuencias

- Cualquiera puede reutilizar y adaptar el contenido si cita y comparte igual.
- Solo se puede incorporar material de terceros con licencia compatible (CC BY, CC BY-SA, dominio público).
- Se puede revisar la licencia del código si aparece un riesgo de apropiación cerrada.
