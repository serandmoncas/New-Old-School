# Rúbricas de calidad

Cada criterio se califica **0 (no cumple), 1 (cumple a medias), 2 (cumple)**. Un artefacto se aprueba con **todos los criterios en 1 o más y al menos 80 % del puntaje máximo**. Un 0 en un criterio marcado con ⚠ bloquea la aprobación.

## Explicación de un concepto

| Criterio | Qué se revisa |
| --- | --- |
| ⚠ Exactitud | No hay errores conceptuales ni datos inventados; lo dudoso está marcado `VERIFICAR` |
| Claridad | Un estudiante de 12 años lo entiende; frases cortas; jerga explicada |
| Ejemplo cotidiano | Al menos un ejemplo de la vida real, que funcione fuera de una gran ciudad |
| Puente académico | Conecta explícitamente con el concepto académico de `conecta_con` |
| Brevedad | Se lee en menos de 10 minutos |
| Núcleo vs. local | No mete leyes, montos o entidades de un país en el núcleo |

## Ejercicios

| Criterio | Qué se revisa |
| --- | --- |
| ⚠ Respuesta correcta | Cada ejercicio tiene solución verificada |
| Progresión | Van de fácil a difícil; los primeros son resueltos paso a paso |
| Variedad | Mezcla cálculo, interpretación y decisión |
| Contexto real | Situaciones creíbles para el público |
| Retroalimentación | Las soluciones explican el razonamiento y los errores típicos |

## Caso práctico / evaluación con evidencia

| Criterio | Qué se revisa |
| --- | --- |
| ⚠ Seguridad | No pide nada riesgoso ni datos personales sensibles |
| Autenticidad | Requiere hacer algo real, no repetir de memoria |
| Criterios claros | El estudiante sabe qué se espera y cómo se evalúa |
| Factibilidad | Se puede hacer con celular básico y sin gastar dinero |

## Adaptación local

| Criterio | Qué se revisa |
| --- | --- |
| ⚠ Vigencia | Leyes, entidades y cifras actuales, con fuente y fecha de consulta |
| Fidelidad al núcleo | No contradice ni duplica el nodo del núcleo; lo complementa |
| Lenguaje local | Usa el vocabulario y los ejemplos del país |

## Traducción

| Criterio | Qué se revisa |
| --- | --- |
| ⚠ Fidelidad | Mismo significado que el original |
| Naturalidad | Suena escrito por un hablante nativo, no traducido |
| Adaptación cultural | Ejemplos y unidades ajustados cuando hace falta |
